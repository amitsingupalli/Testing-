# 🤖 Agent Mentor

> Your Personal AI Agent Developer Learning Coach

Agent Mentor is a structured, interactive learning platform designed to take you from beginner to job-ready **AI Agent Developer**. Built for B.Tech CS/IT students and self-learners who want to build real AI agent projects.

## ✨ Features

- 📚 **15-Level Mastery Path** — From Python basics to production multi-agent systems
- 🗺️ **Interactive Roadmap** — Visual learning path with progress tracking
- 📅 **12-Week Study Plan** — Structured daily schedule (1-2 hours/day)
- 💻 **Hands-on Lessons** — Code examples, practice tasks, and mini-projects
- 🧪 **Quizzes & Assessments** — Test your understanding at every level
- 📊 **Progress Dashboard** — Track completed topics, streaks, and achievements
- 🌙 **Dark/Light Theme** — Comfortable reading experience
- 📱 **Fully Responsive** — Learn on any device

## 🛠️ Tech Stack

- HTML5, CSS3, JavaScript (Vanilla)
- Prism.js for code syntax highlighting
- LocalStorage for progress tracking
- GitHub Pages for deployment

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/amitsingupalli/agent-mentor.git
   cd agent-mentor
   ```

2. Open index.html in your browser or use a local server:
   ```bash
   python -m http.server 8000
   ```

3. Start learning from Level 0!

## 📖 Mastery Path

| Level | Topic | Description |
|-------|-------|-------------|
| 0 | Setup and Fundamentals | IDE, terminal, Python installation |
| 1 | Python for AI Agents | Data types, async/await, Pydantic |
| 2 | Git, GitHub and Linux | Version control, environments |
| 3 | APIs and Backend Basics | REST, HTTP, JSON, authentication |
| 4 | LLM Fundamentals | How LLMs work, prompt engineering |
| 5 | LLM APIs and Tool Calling | OpenAI/Gemini APIs, function calling |
| 6 | RAG and Vector Databases | Embeddings, Chroma, document QA |
| 7 | Agent Architecture | ReAct, memory, planning, tool use |
| 8 | Agent Frameworks | LangChain, LangGraph, CrewAI |
| 9 | Multi-Agent Systems | MCP, orchestration, HITL |
| 10 | FastAPI and Databases | REST APIs, PostgreSQL, MongoDB |
| 11 | Docker and LLMOps | Containers, cloud, monitoring |
| 12 | Frontend for Agents | React/Next.js, chat UIs, streaming |
| 13 | AI Safety and Testing | Guardrails, red teaming, evaluation |
| 14 | Portfolio and Career | Projects, interviews, freelancing |
